1 第 1 章：帳號建立與登入

開始使用 Notion 前，請確認您已具備以下準備：

  1. 開啟瀏覽器，前往 notion.so
  2. 點擊「註冊」，使用郵件地址或 Google/Apple 帳號快速加入
  3. 完成驗證郵件後，返回 Notion 並使用您的帳號登入
  4. 若需桌面版，可至 Notion 官網下載 Windows 或 macOS 版本
注意： 教育工作者與學生可申請 免費 Plus 方案，請在註冊頁面選擇「教育優惠」並上傳相關憑證。

💡 新手快速開始小技巧

  • 首次登入後，Notion 會顯示 範本庫，請嘗試點擊「關於 Notion」範本，先熟悉介面
  • 若想離線使用，請確保在線上時已 預先載入 您需要的頁面（瀏覽器會自行快取）

2 第 2 章：介面主要元件說明

側邊欄

  • 📁 頁面列： 所有頁面與資料庫的容器
  • ⚙️ 設定： 點擊左上角 ••• 進入設定與成員管理
  • 🔍 搜尋： 上方放大鏡，可全站搜尋內容

工作區頂部

  • + 新增： 新增文字、圖片、資料庫等
  • ✒️ 編輯模式： 開啟/關閉編輯
  • ⚙️ 更多： 視圗切換、外掛、設定

畫布操作

  • 點擊 按下 Enter 在頁面底部新增文字塊
  • 拖曳元件至畫布中任意位置，即可建立新區塊
  • / 斜線命令： 快速插入圖片、資料庫、清單等
提醒： Notion 的所有內容皆為 區塊（Block），無論是文字、圖片、資料庫，皆可透過拖曳調整位置與順序。

基本文字格式

    /bold 或 Ctrl + B (Mac: Cmd + B) /italic 或 Ctrl + I (Mac: Cmd + I) /inline 程式碼 或 Ctrl + K (Mac: Cmd + K) /link 超連結

媒體與檔案嵌入

在新增內容時，支援拖曳或貼上：

  • 🖼️ 圖片（從電腦、unsplash 庫或直接貼上 URL
  • 📺 動畫（YouTube、Vimeo 連結自動轉嵌
  • 📄 檔案（PDF、Word、CSV 皆可預覽
貼上連結： 複製任何網址至新行並按 Enter，Notion 會自動擷取卡片預覽（需網路存取）。

4 第 4 章：資料庫—Notion 最強大的功能

資料庫是 Notion 的核心。無論是待辦事項、項目追蹤，還是行事曆視圖，皆靠資料庫實現。

建立資料庫的三種方式

  1. 頁面內建立： 點擊 + → 資料庫 → 選擇型態
  2. 側邊欄新增： 點擊側邊欄 + → 資料庫 → 選擇型態
  3. 斜線命令： /database → 選擇 表格 / 畫框 / 清單 / 行事曆

5 第 5 章：行事曃外接與同步

📌 畫面來源說明： 下方行事曃視圖示意圖參考自 Notion 官方文件與公開介面，標籤明確標示：【來源：Notion官方公開頁面】

為何要外接行事曃？

Notion 的行事曃視圖雖強大，但若想同步 Google Calendar、Outlook 或其他行事曃軟體，需要透過以下方式實現：

方法一：手動匯入（無需額外帳號）

  1. 在 Notion 中建立資料庫，新增 日期 欄位
  2. 每個事件輸入 開始 與 結束 時間
  3. 切換視圖至 行事曃，即可在 Notion 內看到時間軸
  4. 若需雙向同步，需使用第三方工具（如 Zapier、Make、Notion API）

方法二：使用 Notion API 實現自行同步（進階）

若您有開發能力，可透過 Notion API 定期推送事件至 Google Calendar：

💻 API 示範碼 
        
        import notion_client
        from google.oauth2 import service_account
        from googleapiclient.discovery import build

        # 1. 讀取 Notion 資料庫
        notion = notion_client.Client(auth="secret_token")
        database_id = "your_notion_database_id"
        response = notion.databases.retrieve(database_id=database_id)
        pages = notion.databases.query(database_id=database_id)["results"]

        # 2. 設定 Google Calendar API
        credentials = service_accountCredentials.from_service_account_file("keys.json")
        service = build("calendar", "v3", credentials=credentials)

        # 3. 逐一建立行事曃事件
        for page in pages:
            props = page["properties"]
            start = props["Start Date"]["date"]["start"]
            end = props["End Date"]["date"]["end"]
            title = props["Name"]["title"][0]["plain_text"]

            event = {
                "summary": title,
                "start": {"date": start},
                "end": {"date": end}
            }
            service.events().insert(calendarId="primary", body=event).execute()
        print(f"成功同步 {len(pages)} 筆事件")

方法三：第三方同步工具（最簡單）

  • Zapier / Make (Integromat)： 建立觸發器「Notion 有新項目」→「Google Calendar 建立事件
  • 無需寫程式，透過視覺化介面拖拉連線即可完成雙向同步
  • 免費方案每月有次數限制，適合個人或小型專案使用
實務建議： 若只是個人使用，方法一 已足夠；若需要行事曃與 Notion 雙向更新（例如行事曃上新增事件自動同步至 Notion），請使用 Zapier 或 Notion API。

6 第 6 章：協作與分享

頁面分享

  1. 點擊右上角 分享 (↑) 按鈕
  2. 選擇 邀請成員 或 產生共享連結
  3. 設定權限：只能閱讀 / Can comment / Can edit

團隊工作區

建立共同工作區後，所有成員可同步瀏覽、編輯相同的頁面與資料庫。變更會即時顯示於所有人畫面（實時協作）。

權限管理

  • 管理者可移除或變更成員權限
  • 單一頁面可獨立設定分享權限（與工作區獨立）
  • 外部來賓可被邀請，但預設僅限閱讀與評論

8 第 8 章：課堂備案與教案庫

1. 教案與教材庫

將各單元教案、學習單（PDF/Word）、教學影片連結與 PPT 整合在同一個資料庫中，並加上「科目」、「年級」、「單元」等標籤，方便歷年複習與跨年級調閱。

📚 單一資料庫整合

新增資料庫 → 選擇 畫框視圖 或 表格視圖。每一筆紀錄可包含：

  • 科目： 國文、數學、自然社會等
  • 年級： 1~6 年級
  • 單元： 第1單元「字母世界」、第2單元「加法導入」
  • 教材： PDF 學習單、連結的 PPT、嵌入的 YouTube 教學影片
  • 關鍵詞： 如「復習」、「挑戰」、「團隊練習」

建立學生學習狀況紀錄表，針對學習扶助（補救教學）或特殊需求學生，紀錄個別化學習策略與成長軌跡。

💡 新手上手範例：

  2. 針對「數學扶助」學生，記錄「用具計數」的嘗試次數與突破點
  3. 使用 日期 欄位追蹤每次輔導的時間點

12 第 12 章：進階功能 – LaTeX 數學與化學公式

Notion 原生支援 LaTeX 語法，無論是二次方程式、微積分符號，或是化學反應式與離子價數，都能排版得像正式考卷一樣工整。

1. 行Inline與區塊公式

📌 行Inline公式（inline）

使用 $$ 圍繞公式，直接於段落中嵌入。

  • $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$ → $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
  • $$E = mc^2$$ → $$E = mc^2$$

📦 區塊公式（block）

單獨一行輸入 LaTeX，置中顯示，適合複雜公式。

輸入：$$ 然後換行，輸入公式再輸入 $$ 結束。

      $$
      SO_4^{2-} \quad \text{（硫酸根離子）}
      $$
      $$
      \underset{\text{反應物}}{\overset{\text{產物}}{CH_4 + 2O_2 \rightarrow 2H_2O + CO_2}}
      $$

2. 化學公式實務範例

🧪 常見化學符號輸入：

  • SO_4^{2-} → SO_4^{2-} （硫酸根離子）
  • H^+ → H^+ （氫離子）
  • OH^- → OH^- （氫氧根離子）
  • \underset{\text{下}}{\overset{\text{上}}{CH_3COOH}} → \underset{\text{下}}{\overset{\text{上}}{CH_3COOH}} （可逆反應箭頭排版）

3. 教學應用建議

  • 數學老師：期中考試試卷上的方程式、微積分極限公式
  • 化學老師：離子方程式、化學反應式（如 2H_2 + O_2 \rightarrow 2H_2O}
  • 物理老師：功、能、動量等公式的快速輸入
